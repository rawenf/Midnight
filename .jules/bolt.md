## 2024-05-30 - Expensive Synchronous Array Operations in Render Path\n**Learning:** The codebase exhibits a pattern of performing expensive synchronous array operations (like sorting and filtering large lists such as `realPins`) directly in the component render path. Since React components re-render frequently, these heavy operations can block the main thread and cause UI stutter.\n**Action:** Always wrap expensive data transformations (like `.filter` and `.sort` on large datasets) with `useMemo` to ensure they only re-run when their explicit dependencies change, rather than on every render.
